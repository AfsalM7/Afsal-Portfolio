# Afsal Portfolio 🙌

**1.Human Resource Employee Attrition Analysis**🤖

Project Link: [HR Employee Attrition Analysis](https://github.com/AfsalM7/HR-Attrition-Analysis)

Tools: Python, MySQL, Excel, Power BI

Description: Examined employee attrition drivers on the IBM HR Analytics dataset (1,470 employees). Performed EDA in Python, used SQL window functions in MySQL to quantify attrition by role and overtime status, validated findings in Excel PivotTables, and built a Power BI dashboard with DAX measures — surfacing a 66.7% attrition rate among overtime Sales Reps.


**2.Customer Shopping Behavior Analysis** 🛍️

Project Link: [Customer behavior & Sales analysis](https://github.com/AfsalM7/Customer-behavior-Sales-analysis/blob/main/README.md)

Tools: Python, PostgreSQL, Power BI ,Azure SQL Database, Excel

Description: Analyzed customer shopping behavior across 3,900 transactions to uncover spending patterns, customer segments, and subscription behavior. Cleaned and engineered features in Python, ran 10 structured business-question queries in PostgreSQL (revenue by gender, customer segmentation, discount-dependent products, and more), and built an interactive Power BI dashboard to guide retention and marketing recommendations.
